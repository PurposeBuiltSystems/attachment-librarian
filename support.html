Add-in: Attachment Librarian

What it does

Indexes every file attachment in your mailbox, groups versions of the same document together (Budget_v2 / Budget FINAL / Budget (1) are one lineage, newest first), and opens the carrying email in one click.

How to use it

  1. Open any message in Outlook and click Attachment Librarian on the ribbon.
  2. Click Index my attachments. Sign in / consent the first time (Microsoft prompt). The add-in only reads your own mailbox.
  3. Search by file name, sender, or subject. Expand a document to see its versions; Open email takes you to the message that carried that version.

Options

  • Days back: how far back to index (default 90, up to 365).

Good to know

  • Metadata only: the index reads file names, sizes, senders, and dates — never the file contents.
  • Version grouping is best-effort: it recognizes common patterns (v2, FINAL, draft, (1), dates). Unusually named files may appear as separate documents.
  • Inline images are skipped — signature logos aren't documents.

Troubleshooting

  • Button doesn't appear: make sure you're on a Microsoft 365 / Exchange Online account viewing a message.
  • Indexing is slow: large windows over attachment-heavy mailboxes take longer — reduce "Days back".
  • The email didn't open: some clients can't open messages programmatically; the add-in then opens it in Outlook on the web.

Privacy

Your email never leaves Microsoft 365 — indexing runs in your own Outlook session and we never receive your data. See the Tutorial · Privacy Policy · Security & Trust Center.
