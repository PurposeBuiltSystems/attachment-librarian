Attachment Librarian

Every attachment in your mail, grouped by document, versions newest-first.

Version lineage Instant search Read-only No data collection Free

Why

"Someone emailed me that spreadsheet… in March? Was Budget_v3_FINAL_revised the latest, or Budget (2)?" Outlook's attachment search can't answer that. The Librarian can.

What it does

  • Indexes every file attachment across your mailbox (metadata only — never file contents).
  • Groups versions — v2, FINAL, draft, (1), dated copies of the same document become one lineage, newest first.
  • Finds fast — search by file name, sender, or subject; one click opens the email that carried the version you need.

Privacy by design

No servers, no accounts, no analytics. A single read-only permission (Mail.Read, your own mailbox), deterministic logic in your own Outlook session, inside the Microsoft 365 boundary. We never see your email. Read the privacy policy.
